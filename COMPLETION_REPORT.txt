🚀 QUICK START (5 MINUTES)

1. Install IBKR Support
   $ pip install "tradingagents[ibkr]"

2. Create & Configure .env
   $ cp .env.example .env

   Edit .env and add:
   TRADINGAGENTS_IBKR_ENABLED=true
   TRADINGAGENTS_IBKR_PORT=7497
   TRADINGAGENTS_IBKR_ACCOUNT=DU12345678
   TRADINGAGENTS_IBKR_PAPER=true
   TRADINGAGENTS_USE_LOCAL_DATA_CACHE=true

3. Enable API in TWS/IB Gateway
   File -> Global Configuration -> API -> Settings
   Check "Enable ActiveX and Socket Clients"

4. Test Connection
   python -c "from tradingagents.brokers.ibkr_client import IBKRClient; \
   print('Connected!' if IBKRClient().get_account_summary() else 'Error')"

5. Download Data
   $ python scripts/download_ibkr_data.py --tickers AAPL NVDA --days 365

6. Run Backtest
   $ python examples/ibkr_backtest_example.py
